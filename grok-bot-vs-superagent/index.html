幕 3 · 三个真差异

差异不在措辞，在机制

左右并置；每步只讲一处真正不同的实现方式。所有判断按 A/B/C 标注。

1 · 准入是程序还是人

一边先过确定性矩阵，一边没有这个对象
dsh-superagent · A

程序层 gate() 是纯函数、不调模型，查 3×2 准入矩阵，把每条事件判成 explicit / inferred / ignore，再交给模型 Eval。src/policy.ts:167-211。

export type Admission = 'explicit' | 'inferred' | 'ignore'
export const ADMISSION_OPTIONS = { listedUnaddressed: ['inferred', 'ignore'], unlistedAddressed: ['explicit', 'inferred', 'ignore'],
  unlistedUnaddressed: ['inferred', 'ignore'] } as const satisfies Record<AdmissionCell, readonly Admission[]>
Lauren Tan 工作流 · C

准入由协调者 / 人决定：文档要求人先看清再放权，但没有「准入矩阵」这样的对象，也没有对应的状态机实现可查——她文档里不存在这个对象（C）。

2 · 审查者是不是独立实体

一边有专门的审查 agent，一边没有这个角色
dsh-superagent · A

Eval 判断的是「该不该接单」，不是代码审查。orchestrator_* 工具面里没有独立审查角色（src/app/tools/main.ts:125-153、:223-239）。

Lauren Tan 工作流 · A

“the agent that judges a change is never the one that wrote it”
评判改动的 agent 从未写过这段代码。

“it spawns a reviewer on a different model family”
审查者换一个模型家族。两句均出自 06-verify-and-ship.md。

3 · 状态机 vs 经验清单

一边是可查对象，一边是文档化规矩
dsh-superagent · A

Mandate（不可变授权）、Subscription（Thread↔Ticket 多对多）、Ticket（自带状态机）都是领域里的可查对象，定义见 docs/001-domain.md。

Lauren Tan 工作流 · A

pstack 给的是 24 条原则 + 22 个 playbook：文档化规矩，靠 agent 遵守；没有强制状态机，也没有「工单」这样的运行时对象。

幕 4 · 两边共同的硬规矩

形状不同，底线相同

三条两边都认的规矩；左右并置，正面收束。

1 · 证据先行

说了不算，跑出来才算
Lauren Tan · A

“"It compiles" is not evidence.”
「能编译」不是证据；要在运行中的应用里验证真实行为。06-verify-and-ship.md。

dsh-superagent · A

程序层 gate() 先筛（src/policy.ts:167-211）；对外只有 answer / result / attention 三种用途，进度不许外发（src/app/tools/main.ts:223-239）。

2 · 时间不是完成条件

「跑了多久」不等于「做完了」
Lauren Tan · A

“a duration is not a finish condition”
可检查的完成条件，而不是「跑 8 小时」。07-overnight.md。

dsh-superagent · A

Ticket 由 Eval 创建、带不可变 Mandate（接单凭证），状态自己定义、不跟随 Session；完成看状态而非时长（docs/001-domain.md）。

3 · 渐进放权

先看着它跑，再逐步松手
dsh-superagent · A

默认 accept mode: observe（只记录不执行），再开到 auto；代码默认值见 src/policy.ts:84。

Lauren Tan · A

“Autopilot-stack is Autopilot-full without the merge. You wake up to verified PRs, each with its verdict, and you review and land them yourself.”
先 Autopilot-stack（人合并），再 Autopilot-full。07-overnight.md。
